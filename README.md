## 結論から

**SA-1のROM吸い出しには CIC認証が必要です。** そして
**カートにクロックを与えてはいけません**（与えるとSA-1が起きてバスを掌握する）。

    Super Mario RPG (Japan)                      5527071e
    Hoshi no Kirby Super Deluxe (Japan)          151bd470
    Hoshi no Kirby Super Deluxe (Japan) (Rev 2)  1f35f230

> **2026-08-29 訂正:** 一時期ここに「CIC認証は不要」と書いていた。**誤りだった。**
> 根拠にした実験は「認証を何度も通したあとに認証なしで試して成功した」というもので、
> 順序による交絡があった。一度も認証していない状態から試すと **0/16**、
> 認証を有効にすると **3回中2回成功**。詳細は NOTES.md を参照。

解析としては、本家CIC(D411)の逆アセンブルとSuperCICのソースから
1ビット=372パルス、1ラウンド=(16−k)ビットといった値を実測で確認し、
実機のKeyとラウンド0の握手を成立させるところまで到達しています。
ラウンド2は未解決ですが、**ROMの吸い出しにはラウンド0で足ります。**

## 読むなら NOTES.md から

このノートは成功手順ではなく、**外した仮説の記録**として書いてあります。
同じ症状が電源・接触・タイミング・バス調停のどれからも出ること、
検証していない測定器を信用すると全実験が無効になること、
1回の陰性を結論にしてはいけないこと——このあたりが実際に高くついた教訓です。
